# Oradia

Oradia is a calm, muted, green-forward dark theme for VS Code, designed for long,
focused sessions across many languages and tuned for a Copilot CLI workflow.

I built Oradia around the idea that visual weight should track importance. Warmth and
saturation are reserved for signals such as errors, focus, dirty state, and active
elements, while the rest of the interface stays quiet. Its palette is also a primary
reference for the visual direction I want to explore for this personal website.

The theme includes an ANSI terminal palette, focused-state UI colors, subtle bracket
nesting cues, and optional highlighting for interpolated expressions.
